# Example values pack: scripture-grounded (optional, off by default)

The kit's author runs his steward with a values check grounded in his faith as a follower of Jesus. This pack
shows how that looks, as one example of grounding the `values-check` skill in a tradition you hold. It is not
installed by default and nothing in the kit depends on it.

To use it, copy `principles.md` over `shared/skills/values-check/principles.md` in your hub, commit, and run
`python3 tools/sync.py`. Edit freely; your convictions are yours.

How it is meant to work: the check guides and never blocks. It never adds a verse or a religious word to the
draft itself, never preaches, and applies the principle silently when the reader does not share the faith. The
verse is for the owner's own reflection, in the note only.

Scripture links go to the Berean Standard Bible on Bible Hub (public domain). References only.
